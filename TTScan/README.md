# เช็คพาสงาน (TTScan)

แอป Android สแกน QR บนใบ TT เพื่อเช็คว่างานนั้นถ่ายรูปเก็บแล้วหรือยัง
ถ้ายังไม่ได้ถ่าย จะให้ถ่าย 2 รูป แล้วสร้างโฟลเดอร์ชื่อเดียวกับ QR พร้อมเซฟรูปให้อัตโนมัติ

## วิธีใช้งาน

1. เปิดแอปครั้งแรก เลือก **ที่เก็บงาน** (โฟลเดอร์ในเครื่องหรือ SD card) แอปจะจำไว้ เปลี่ยนได้ทุกเมื่อด้วยปุ่ม "เลือกที่เก็บงาน"
2. เล็งกล้องไปที่ QR บนใบ TT
   - **✅ สีเขียว** = มีโฟลเดอร์และมีรูปครบแล้ว ไม่ต้องถ่ายซ้ำ
   - **🆕 สีส้ม** = ยังไม่ได้ถ่าย แอปเข้าโหมดถ่ายรูปให้เอง
3. กด "ถ่ายรูป" 2 ครั้ง พอครบแอปจะสร้างโฟลเดอร์และบันทึกรูปทันที แล้วกลับไปโหมดสแกนต่อ

ตัวอย่างผลลัพธ์ในที่เก็บงาน:

```
FG-3673120100-01/
    FG-3673120100-01_1.jpg
    FG-3673120100-01_2.jpg
```

ปุ่ม "รายการที่ถ่ายแล้ว" แสดงโฟลเดอร์งานทั้งหมดที่มีในที่เก็บ

## ทำเป็นไฟล์ติดตั้ง (APK)

### วิธี A: Android Studio
1. เปิดโฟลเดอร์ `TTScan` ด้วย Android Studio แล้วรอ Gradle Sync
2. ต่อมือถือ (เปิด USB debugging) แล้วกด Run หรือเมนู Build > Build APK(s)
3. ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`

### วิธี B: GitHub Actions (ไม่ต้องลง Android Studio)
1. สร้าง repository บน GitHub แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
2. ไปแท็บ Actions แล้วรัน workflow "Build APK"
3. ดาวน์โหลด `TTScan-debug-apk` จากหน้าผลลัพธ์ แตก zip ได้ `app-debug.apk` ส่งเข้ามือถือแล้วติดตั้ง (อนุญาตติดตั้งจากแหล่งอื่น)

## หมายเหตุ

- ไม่ต้องใช้อินเทอร์เน็ตตอนใช้งาน โมเดลสแกน QR ฝังอยู่ในแอป
- ชื่อโฟลเดอร์ใช้ข้อความใน QR ตรง ๆ ถ้ามีอักขระที่ระบบไฟล์ไม่รับ (`/ \ : * ? " < > |`) จะถูกแทนด้วย `_`
- โฟลเดอร์ที่มีรูปน้อยกว่า 2 รูป ถือว่ายังไม่ครบ แอปจะให้ถ่ายใหม่และเขียนทับ
- ขั้นต่ำ Android 7.0 (API 24)
